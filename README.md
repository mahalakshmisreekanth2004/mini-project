# 🌱 AgriCircle – Social Networking for Farmers

**AgriCircle** is a cross-platform mobile application designed to connect farmers through a digital community where they can share agricultural knowledge, exchange farming experiences, and communicate with one another.

Inspired by social networking platforms, AgriCircle provides features such as posts, likes, comments, user profiles, search, translation, and chat to encourage collaboration and knowledge sharing within the agricultural community.

## ✨ Features

* 🔐 **User Authentication** – User registration and login.
* 👤 **User Profiles** – Create and manage personalized profiles.
* 📝 **Create Posts** – Share farming experiences, agricultural practices, and updates.
* ❤️ **Likes and Comments** – Engage with posts and exchange ideas.
* 💬 **Chat and Messaging** – Communicate with other users.
* 🔍 **Search and Explore** – Discover users and agricultural content.
* 🌐 **Translation Support** – Make shared content more accessible across language barriers.
* ☁️ **Cloud-Based Storage** – Store application data and uploaded media using Firebase services.

## 🎯 Project Objectives

* Build a dedicated social networking platform for farmers.
* Encourage knowledge sharing and collaboration within the agricultural community.
* Make agricultural experiences and information easier to share.
* Provide convenient communication between farmers.
* Develop an intuitive, cross-platform mobile application.

## 🛠️ Tech Stack

| Technology              | Purpose                                       |
| ----------------------- | --------------------------------------------- |
| Flutter                 | Cross-platform mobile application development |
| Dart                    | Programming language                          |
| Firebase Authentication | User authentication                           |
| Cloud Firestore         | Database and real-time data management        |
| Firebase Cloud Storage  | Image and media storage                       |
| Git & GitHub            | Version control and project hosting           |

## 🏗️ Application Architecture

AgriCircle uses Flutter for the frontend and Firebase for backend services.

* **Frontend:** User interface, navigation, and social interactions.
* **Authentication:** User registration and login.
* **Database:** Management of user profiles, posts, comments, likes, and chat messages.
* **Cloud Storage:** Storage of uploaded images and other supported media.
